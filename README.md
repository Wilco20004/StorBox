# StorBox Home Assistant Add-on

A self-hosted home inventory tracker: Locations → Containers (with a shelf/
position) → Items, with tags and photos. No login, no monetary values —
built from scratch (inspired by [Homebox](https://github.com/sysadminsmedia/homebox))
to run natively as a Home Assistant add-on with a sidebar panel and embedded
(Ingress) UI.

## Add-ons

This repository contains the following add-on:
